Consensus & Routing Configuration

Customize replication guarantees, quorum thresholds, and load-balancing placement policies.

Replication Consistency Policy

Quorum Strong: Writes are only acknowledged once committed to both Primary and Replica nodes.
Eventual: Primary writes acknowledge immediately; replica updates are dispatched asynchronously.
Causal: Enforces monotonic causality across updates.

Load Balancing Chunk Placement

Master evaluates real-time node telemetry to balance incoming writes and route reads to whichever replica holder has lower latency.
